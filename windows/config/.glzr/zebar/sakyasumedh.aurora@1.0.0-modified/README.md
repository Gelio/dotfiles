# Aurora

Floating three-island top bar for Zebar + GlazeWM.

- **Left island**: Windows logo (click = Start menu, right-click = Settings), workspaces
  (click to focus, scroll to cycle), focused window (click = toggle floating).
- **Center island**: date + time (click = calendar / notification center, right-click = date settings).
- **Right island**: now-playing (click = play/pause, hover for prev/next), tiling direction,
  Bluetooth (click = settings, right-click = pair; badge = connected count), Wi-Fi (click = network flyout), RAM and CPU (click = Task Manager),
  battery (click = power settings), volume (click = mute, scroll = adjust, right-click = mixer),
  weather (click = forecast).

Edit `styles.css` `:root` variables to retheme. Everything uses Nerd Fonts webfont icons.
